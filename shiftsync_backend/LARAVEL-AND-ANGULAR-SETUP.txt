**To setup IAOS Laravel Project**

Dummy Data

php artisan serve

php artisan migrate

php artisan db:seed 

php artisan schedule:work

**Setup Laravel User Side**

1. composer install
2. npm install
3. cp .env.example .env
4. php artisan key:generate

.env setup

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=inout_db
DB_USERNAME=root
DB_PASSWORD=Password1!

MAIL_MAILER=smtp
MAIL_HOST=[smtp-mail.outlook.com](http://smtp-mail.outlook.com/)
MAIL_PORT=587
MAIL_USERNAME=<outlook_email>
MAIL_PASSWORD=<outlook_password>
MAIL_ENCRYPTION=STARTTLS
MAIL_FROM_ADDRESS=<outlook_email>
MAIL_FROM_NAME="Support Team"

Database Setup

1. php artisan migrate
2. php artisan db:seed 
3. php artisan schedule:work (wait 1 minute until done/sucess)

php artisan serve

**Setup Angular Admin Side**

npm install -g @angular/cli@16

npm install

ng serve
